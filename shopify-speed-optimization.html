Why it matters

Speed is part of the shopping experience

Shoppers on mobile data don't wait for a page that is still loading scripts. Google also measures real-user loading, responsiveness and visual stability as Core Web Vitals and uses them as part of how it evaluates pages. A faster store helps both: more visitors see your products, and more of them stay long enough to buy. If conversion is the real goal, see Shopify CRO too.

The metrics

Core Web Vitals, in plain language

  • LCP (Largest Contentful Paint): how long the main content, usually the hero or product image, takes to appear. Google's “good” threshold is 2.5 seconds or less.
  • INP (Interaction to Next Paint): how quickly the page responds when someone taps a variant, opens the menu or adds to cart. Good is 200 milliseconds or less.
  • CLS (Cumulative Layout Shift): how much the page jumps around while loading. Good is 0.1 or less.

Lab scores from Lighthouse and PageSpeed Insights are useful for diagnosis, but the numbers that count are field data from real visitors, which Shopify also shows in its web performance report in the admin.

Where stores get slow

The usual suspects

  • App bloat. Apps that load scripts on every page, and code left in the theme after an app was uninstalled.
  • Heavy media. Oversized hero images, autoplay videos and sliders above the fold.
  • Third-party tags. Several analytics, ads and chat scripts all competing for the main thread.
  • Theme code. Render-blocking CSS and JavaScript, large Liquid loops, and media without reserved space, which causes layout shift.
The work

What Shopify speed optimization involves

1. Measure

Field data first, then PageSpeed Insights, Lighthouse and Shopify Theme Inspector to see which templates, sections, apps and scripts cost the most.

2. Remove and replace

Leftover app code is removed, apps that duplicate each other are consolidated, and small features handled by heavy apps are rebuilt as lean theme code or theme app extensions.

3. Fix the theme

Responsive images with the right sizes, lazy loading below the fold, priority loading for the main image, deferred scripts, sensible font loading and fixed dimensions for media so nothing jumps.

4. Keep it fast

Changes ship through Git and Shopify CLI so they can be reviewed and rolled back, with a short list of rules for adding new apps and sections without undoing the work. Read more about releases on the speed and launch page.

Common questions

Shopify speed optimization, answered

Can you get my store a perfect PageSpeed score?

I won't promise a specific score. Lab scores swing between runs and depend on apps and tracking you may need. The goal is good Core Web Vitals for real visitors and a store that feels fast.

Does uninstalling an app make my store faster?

Not always. Some apps leave code in the theme after they are removed. Part of the audit is finding and cleaning up that leftover code.

Do I need a new theme to make my store fast?

Usually not. Most stores can be made much faster by fixing images, scripts and app code in the existing theme. A rebuild only makes sense when the theme itself is the bottleneck.

Does site speed affect SEO?

Core Web Vitals are one of the signals Google uses in its page experience evaluation. Relevant content matters more, but a fast store helps rankings, crawling and conversion.

Yes, on Shopify and Shopify Plus, including stores with custom checkout extensions, B2B and several markets.
